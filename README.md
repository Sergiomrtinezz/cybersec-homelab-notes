# Cybersecurity Portfolio & Lab Notebook

Bienvenido/a a mi repositorio central de ciberseguridad. Este espacio documenta mi proceso de especialización técnica en seguridad defensiva y ofensiva, estructurado de forma paralela a la finalización de mis estudios de **Grado en Ingeniería Informática** en la **Universidad de Granada (UGR)**.

El objetivo principal de este repositorio es transformar el aprendizaje teórico universitario en competencias prácticas demostrables, mediante la experimentación en entornos controlados, análisis de vulnerabilidades, auditorías de configuración (*hardening*) y resolución metódica de retos técnicos.

---

**Enfoque y Metodología**

El desarrollo de mis habilidades se apoya en tres principios:

1. **Rigor Técnico y Documentación:** Cada práctica, máquina comprometida o laboratorio incluye un análisis de causa raíz, mecanismos internos del sistema operativo o protocolo afectado, y contramedidas de mitigación (*remediation*).
2. **Entornos Aislados y Reproducibles:** Uso de laboratorios locales virtualizados (Kali Linux sobre hipervisores en Linux) y plataformas especializadas para garantizar experimentación segura y controlada.
3. **Perspectiva Dual (Ofensiva/Defensiva):** Entender cómo se explota una debilidad (inyección, desbordamiento, desalineación de permisos) para aprender a diseñar arquitecturas resilientes y políticas de *hardening* efectivas.
